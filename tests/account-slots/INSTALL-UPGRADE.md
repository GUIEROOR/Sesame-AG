# 0.2.6 多账号与私有存储修复版安装说明

适用基线：4380-0.2.6，保留原版私有存储、配置迁移和安全校验。

1. 先在当前模块中导出配置备份，保存到模块私有目录以外。
2. 直接安装本包，覆盖之前交付的同签名 0.2.4-MultiAccount；不要卸载或清除数据。
   本次构建会核对两个实际 APK 的包名、签名和递增的 versionCode。
   官方包或其他签名的包不在这个覆盖安装结论内，若提示签名冲突，请停止安装。
3. 首先打开模块应用。若提示旧配置检查/迁移，按照页面完成 Root 或 Shizuku
   授权及迁移，保持应用前台，直到显示配置可用。不要跳过迁移或手动删除旧目录。
4. 完成后重启目标应用；框架要求重启设备时按提示操作。先登录大号，再切换小号，
   返回模块自动化页面确认两个账号的可执行槽位。新账号仍需分别确认使用协议。
5. 已经被旧版移出的账号，需要手动移入一次；无法从旧数据区分误移除与主动移除，
   因此不会擅自重新启用所有旧账号。最多两个账号可执行。

本次修复：新账号有空槽时可自动建档；中断建档可以继续；超时但资料完整时补确认；
临时读取失败、空快照或进程重启不会撤销已保存槽位；界面显示待建档及已保留槽位；
使用 0.2.6 私有存储事务和资源句柄，不退回共享目录。

请在手机上验收：两账号来回切换、强制停止后重开、设备重启、备份导出后检查文件。
不要为了测试破坏正在使用的配置。若有异常，保留模块日志及构建报告，勿清除数据。

自动回归使用真实私有存储引擎；Android Binder、目录 fsync 与 Root/Shizuku
由测试适配器模拟。实际手机覆盖安装、权限迁移及长期双账号运行尚需真机验证。
